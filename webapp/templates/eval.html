🛡 Defenses applied by the protected agent

Four layers wrap the same base agent. Click any file to see how it's built.

  • Input validation — pattern-based injection detector blocks high-confidence attacks before the LLM sees them. detectors/rules.py
  • Tool gateway — per-tool call budgets + URL/recipient allowlists. Default send_message recipient list is empty (deny-all). agents/protected/gateway.py
  • Tool-result tagging — same RulesDetector re-scans tool output and prefixes suspicious results with [UNTRUSTED_INJECTION_DETECTED] so the LLM treats them as data. detectors/rules.py
  • Output filtering — strips secrets / known exfiltration vectors from the final response before it leaves the agent. detectors/output_filter.py
